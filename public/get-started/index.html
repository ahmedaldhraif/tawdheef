1. Get Tawdheef from GitHub.

Download the source ZIP and extract it. Open the extracted folder in your installed, signed-in Codex or Claude Code. You only need one.

Download from GitHubView source

Release notes and checksums. This is a source app for your computer; Node.js 24 or newer is required.

Prefer Git?
git clone https://github.com/ahmedaldhraif/tawdheef.git
cd tawdheef

Open this folder in your assistant, then follow the same steps below.

2. Ask your agent to set it up.

Paste this into Codex or Claude Code:

Setup request
Set up Tawdheef for me in this folder. Read AGENTS.md and docs/FIRST-RUN.md. Check what already works, then install missing project dependencies, start the app, add browser tools, and connect this project to the assistant I am using. Keep existing settings and data. Help me create or connect my free Tabbio CV using only my real information. Guide me through only the sign-ins or choices that need me; I will enter credentials in the local connection form. Check setup again and tell me the next step. Use get_setup_status (verify:true for the final check), or the equivalent CLI command. Do not change the app's code or design, send applications, create calendar events, or enable schedules during setup.

Your agent checks dependencies, starts the local app and prepares project tools. Accept the project/server trust prompt when shown. A new chat may be needed to load MCP tools.

ChatGPT and Claude web chats do not read local stdio settings. Use the local client above. Read the agent skill.

Prefer manual setup?

In a terminal in the extracted folder:

npm start

This installs missing locked dependencies, builds the screen and starts your local tracker. On Windows, you can also open Start Tawdheef.cmd.

Add browser tools, then run only the command for your chosen client:

npm run setup -- --browser
npm run agent -- codex --browser
npm run agent -- claude-code --browser

These prepare project settings and the skill. Sign-ins are separate. Preserve custom settings if a conflict is reported; follow the setup guide.

3. Create or connect your free CV.

Keep one current CV in Tabbio for recruiters and your agent. Available worldwide. Already have one? Connect it in the app.

Create your free CVTabbio connection guide
  1. Create your CV in Tabbio using your real experience.
  2. In Tawdheef, open Connections → Tabbio CV → Connect and complete sign-in.
  3. Choose your assistant under AI assistants, then use Check connections.

A successful check confirms the app can read your CV and your selected assistant is signed in. A connected CV is required for Run; browsing directories and manual tracking work without it.

Want your agent to update your CV too?

Tawdheef reads your CV. For CV editing and sharing, connect Tabbio directly to your agent through its own MCP or CLI. These are separate connections.

Tabbio agent request
Help me connect Tabbio using its official MCP or CLI guide. Read my current CV, ask me for missing facts and help keep it up to date. Show proposed edits before changing it. Ask before publishing it, changing employer visibility or turning on Open to work. Do not invent experience.

Use Tabbio’s current setup instructions and complete sign-in yourself. Free connection and CV tools are available; paid AI features have their own limits.

Email is optional for browser applications. Connect a mailbox for email applications and reply checks. Gmail and Outlook need your own OAuth registration or a supported bridge; your agent can guide you. Calendar and schedules can wait.

4. Choose a directory. Start a run.

The UAE starter directory is included. Add another country pack or import your own list.

Open Run, set your role and location preferences, and choose companies. Your agent uses your accounts and records confirmations and replies. Sign-ins, CAPTCHA and required declarations may need you; LinkedIn applications stay manual.

Want a shortlist first? Ask your agent:

Find a shortlist
Use Tawdheef. Read AGENTS.md and call get_agent_context and get_capabilities. Review my UAE directory and connected CV, then suggest a shortlist based on my role and location preferences. Do not send or submit anything.

Costs, privacy and local requirements.

Tawdheef is free and MIT licensed. Your AI client, model usage and connected providers may have their own plans or costs. Tawdheef does not require its own model API key.

The app and agent run on your computer. Your private tracker is available there by default; this website does not host it or make it available on your phone.

Tracking and credentials are stored locally. Credentials are not encrypted at rest by the app. Connected AI, Tabbio, email and careers services communicate online under their own permissions. Read the privacy guide.

This website has no visitor analytics scripts or tracking pixels. Hosting may keep access logs. Tabbio links include readable referral parameters; its own plans and privacy terms apply.
