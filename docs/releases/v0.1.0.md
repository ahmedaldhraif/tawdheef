# Tawdheef 0.1.0 — public preview

A local company directory and job-hunt tracker for you and your AI agent.

## Download and start

1. Download `tawdheef-0.1.0-source.zip` and extract it.
2. Install Node.js 24 or newer.
3. Open **Start Tawdheef.cmd** on Windows, or run `npm start` in the extracted folder on Windows/macOS/Linux. On macOS the `.command` launcher is also provided; OS permission prompts may apply.
4. Open **Connections**, select Codex or Claude Code under AI assistants, and expand **Set up with my agent → Copy instructions**. Paste into that assistant with this folder open. It can prepare the project and guide the remaining sign-ins.
5. Complete account sign-ins in Connections, then use **Check connections**. It verifies the chosen assistant and CV without sending applications.

First launch installs dependencies and prepares local downloads. Internet is needed for installation and connected providers. Later launches reuse the existing build until source files change.

- Gmail/Outlook/iCloud Mail, Google/Outlook/iCloud Calendar, Tabbio CV and optional local bridges.
- Run launches installed Codex or Claude Code with an uncapped company queue, per-company failure recovery, durable email/form intents and real progress. Evidence-based tracking, local background reply refreshes and reports.
- Run can combine multiple company types and directory-specific cities/locations. Optional Progress and Company type columns show account/profile creation, CV uploads/sends and confirmed applications separately; reports include the recorded milestones.

- Fresh installs leave scheduled checks and reports off until you choose a schedule. Existing saved preferences are preserved.
- ApplyMCP-style dot background and subtle floating surfaces, with static touch/reduced-motion behavior and no added runtime library.

## Account setup and current limits

Each person uses their own accounts. Native Google/Microsoft connections need the person's own OAuth application registration; there is no shared publisher client ID in this release. iCloud Mail and Calendar use an Apple app-specific password. Installing MCP settings does not sign into an AI account or any provider.

The tracker is MIT licensed and does not need its own model API key. AI clients and connected providers may have their own costs. Private data stays in `.local`; authorized providers still communicate online. Credentials are not encrypted at rest by the app.

This is a source release requiring Node.js, not a signed desktop installer. Live-account sending and calendar creation require verification after the user connects. LinkedIn actions, sign-in challenges and required declarations remain manual. Background work needs an awake, online computer and never starts fresh applications.

`SHA256SUMS.txt` verifies the downloadable ZIP assets. Country packs, the skill and brand kit are available separately. The source includes the reviewed directory data and builders; generated import files are recreated locally or downloaded as packs. See `docs/QUICKSTART.md`, `docs/REPOSITORY.md` and `docs/CONNECTIONS.md` in the source.
