Questions before you start?

Is it really free?

Tawdheef is free and MIT licensed. Your AI client, model usage and connected providers may have their own plans or costs. Tawdheef does not require its own model API key. See costs and connections.

Do I need to know how to code?

No coding is needed. Open the downloaded folder in Codex or Claude Code and ask your agent to set it up. Node.js 24 or newer is required. Copy the setup request.

Does it apply for me?

Your agent can send emails and complete supported forms when you explicitly start a run for named targets. Sign-ins, CAPTCHAs, provider approvals and LinkedIn steps may need you. See how applications work.

Do I need Tabbio?

You can browse directories and track applications without Tabbio. Run requires a connected Tabbio CV. Create or connect your free CV.

What does Tawdheef mean?

Tawdheef (توظيف) means employment in Arabic. The app is for job seekers anywhere; directory contributions from any country are welcome.

Can I use it on my phone?

The website works on your phone. The local app and agent run on your computer, and the default server is available only there. See local requirements.

Where does my data go?

Your tracking records stay in a local database. AI, CV and email services connect online under their own permissions. Read the privacy guide.

Can I add a country or fix a company?

Yes. Use a pack, fix a link or contribute a directory for any country. Packs include dated sources, not live vacancies. Find packs and contribute.
