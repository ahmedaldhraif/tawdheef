Get started

Download the app, connect your existing client, then use its CV and account tools. The native workflow describes the 0.2 preview; check the selected release version.

Download the appView or clone on GitHub
  1. 1

    Open the app folder

    Extract the complete app, or open the source folder in your existing Codex or Claude Code client. Source needs Node.js 26 LTS or patched Node 24; app packages include Node.

  2. 2

    Connect your agent

    Copy the setup request into your existing client, or run these Codex commands in the source folder.

    npm start npm run agent -- codex

    Using Claude Code? Replace the second command with: npm run agent -- claude-code

    These prepare the app, connect its local MCP tools and install the workflow skill.

  3. 3

    Create or connect your CV

    Create your free digital CV on Tabbio, or connect the one you already have.

    Create your free CVConnect your CV

    Open Connections → Tabbio CV, copy its setup request and complete sign-in in your actual client. Reuse that client’s Tabbio MCP connection and check the real CV there.

    Run copies a request for your existing client. Dated connection reports are not independent provider verification.
