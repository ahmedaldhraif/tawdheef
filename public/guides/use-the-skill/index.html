Set up Tawdheef with your agent

Download the free app, connect Codex or Claude Code and your CV, then find matching jobs and build career profiles.

On this page
InstallAgentCVWorkflowUsePermissionsPrivacy

Find matching jobs and build career profiles, including when no suitable job is open. Tawdheef is a local-first app with its own CLI and local MCP server. Codex or Claude Code does the work using your connected CV and accounts.

Install

Download Tawdheef from GitHub Releases and extract the app's source ZIP.

Download from GitHubRelease notes and checksums

Open the extracted folder in your installed, signed-in Codex or Claude Code. You need Node.js 24 or newer; your agent can guide you if it is missing.

Agent

Copy the setup request into your assistant with the Tawdheef folder open. It checks existing setup, starts the app and connects the local tools and workflow skill.

Setup request
Set up Tawdheef for me in this folder. Read AGENTS.md and docs/FIRST-RUN.md. Check what already works, then install missing project dependencies, start the app, add browser tools, and connect this project to the assistant I am using. Keep existing settings and data. Help me create or connect my free Tabbio CV using only my real information. Guide me through only the sign-ins or choices that need me; I will enter credentials in the local connection form. Check setup again and tell me the next step. Use get_setup_status (verify:true for the final check), or the equivalent CLI command. Do not change the app's code or design, send applications, create calendar events, or enable schedules during setup.

Complete sign-ins and account choices in Connections. Accept your assistant's project/server trust prompt when shown, then use Check connections.

Use the local Codex or Claude Code client; ChatGPT and Claude web chats do not read the app's local MCP settings.

If you prefer the terminal

Run these from the extracted folder to install browser tools, connect Codex and start the app:

npm run setup -- --browser
npm run agent -- codex --browser
npm start

For Claude Code, replace the second command with:

npm run agent -- claude-code --browser

This creates project-only settings for Tawdheef's local stdio MCP server and installs the skill. Existing custom settings are preserved; follow the reported merge instructions if they conflict. Reopen the project or start a new chat so your assistant loads the tools.

The app also has its own CLI: node bin/apply-tracker.mjs help. The screen, CLI and MCP use the same local records. MCP lets a compatible local agent call tools directly; the CLI supports terminal agents and scripts. See the tool reference.

npm run setup -- --all also installs the separate Tabbio CLI. It is optional for this setup. See Connect your agent for connection details.

CV

  1. Create your free CV on Tabbio, or use your existing account. Add and review your real experience, education and skills.
  2. In Tawdheef, open Connections → Your CV → Tabbio CV → Connect and complete sign-in.
  3. Choose your assistant in Connections, then use Check connections. It checks the assistant's sign-in and reads your connected CV.

A readable connected CV is required before Run. You can browse directories and track records without it. See Create or connect your CV if the read needs attention.

Your agent can make the same final check with get_setup_status, using verify:true and the chosen assistant. For the CLI, save this as .local/setup-check.json, replacing codex with claude-code if needed:

{"verify":true,"assistant":"codex"}

Then run:

node bin/apply-tracker.mjs call get_setup_status --input-file .local/setup-check.json

Use your configured private data folder if you changed APPLY_TRACKER_DATA.

To use Tabbio's separate CLI, you can optionally run npm run setup -- --login tabbio and complete its sign-in. Follow the official Tabbio connection guide. Tawdheef reads your connected CV; editing or publishing it through Tabbio is a separate connection and request.

Workflow

Choose the bundled UAE directory or add a country pack. Filter the list by city, company type or status, and select individual companies if you want a smaller scope. Open Run to review the matching company count and actions.

Matching jobs and career profiles are selected by default. Your agent checks vacancies against your CV. When no suitable job is open, it can create or complete a career account, fill your profile and upload your CV where supported. You can change these choices before starting; CV-only emails are optional and off by default.

Career profiles, CV uploads and confirmed job applications are recorded separately. Read the run guide.

Use

In Codex, mention $tawdheef. In Claude Code, use /tawdheef. Give your agent a task below, replacing bracketed text with your own targets or preferences.

Already connected? Install just the skill

App setup already installs the skill. If you only need its guidance in another supported assistant, run:

npx skills@latest add ahmedaldhraif/tawdheef --skill tawdheef

Choose your assistant in the installer. This adds guidance; it does not install the app, connect MCP tools, sign into accounts or authorise job-search actions. Read the actual skill source.

Prompts

Find a shortlist:

Shortlist suitable companies in [directory] for [role and location]. Check the source evidence and my connected CV. Explain the fit and missing information. Do not apply or send messages.

Start a run for matching jobs and career profiles:

Start a run for [company names] in [directory] for [role and location]. Use my real CV and apply to suitable jobs. If no suitable job is open, create or complete my career profile and upload my CV where supported. Reuse existing accounts and check for duplicates. Leave CV-only emails off. Record real outcomes and anything that needs me.

Review existing work:

Check replies for my tracked application threads. Summarise real changes and next actions, then save a local report. Do not start applications, send follow-ups or email the report.

Permissions

Setup and skill installation do not authorise applications, profiles or CV sharing. A requested run covers only the targets and actions you requested. Sign-ins, CAPTCHAs and provider approvals may need you; LinkedIn application steps remain manual. An application needs a real receipt or confirmation, while profile work keeps its own evidence.

Privacy

Tracking data and credentials stay in your local app folder. Connected AI, CV and email services process data under their own permissions and terms. Enter private credentials in Connections, not in chat or public issues.

Tawdheef is free; your assistant account and connected services may have their own costs. Read the privacy guide.
