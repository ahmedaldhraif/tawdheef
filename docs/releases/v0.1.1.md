# Tawdheef 0.1.1 — public preview

Free, open-source auto job apply and application tracking with your agent.

## Start here

1. Download `tawdheef-0.1.1-source.zip` below and extract it, or clone this repository.
2. Open the folder in your installed, signed-in **Codex or Claude Code**.
3. Follow [the setup request](https://github.com/ahmedaldhraif/tawdheef/blob/main/docs/FIRST-RUN.md). Your agent prepares the app; you complete sign-ins.
4. Create a [free Tabbio CV](https://app.tabbio.com?utm_source=tawdheef&utm_medium=github_release&utm_campaign=live_cv), or connect your existing one in **Connections → Tabbio CV**. Select your assistant and use **Check connections**.
5. Choose companies and Run actions. Your agent applies through your accounts and records confirmed outcomes. Sign-ins, CAPTCHA and required declarations may need you. LinkedIn actions stay manual.

Requires Node.js 24+. The tracker is free and MIT licensed; your AI client and connected providers may have their own costs. This is a source release, not a signed desktop installer.

## What changed

- Clear auto-apply and application-tracking positioning across the website, README and agent skill.
- GitHub Releases supply app and pack downloads. GitHub holds the source, public evidence, corrections and contributions.
- A shorter setup path from download to a current Tabbio CV, verified connections and a chosen application run.
- Country packs have GitHub README files, direct download links, import steps and machine-readable indexes. Any country can be contributed.
- Human and agent guides distinguish Tawdheef's CV read connection from Tabbio's own CLI/MCP editing and sharing tools.

## Country packs

Six current GCC packs contain **13,714 organisation/source records**: UAE, Saudi Arabia, Qatar, Oman, Kuwait and Bahrain. Download a pack, extract it, create or select a directory and preview its CSV files before importing. Import all numbered parts into the same directory.

These are dated recruitment research lists, not live vacancies or counts of unique employers. The original 772-record UAE starter is included in a fresh app and overlaps the expanded UAE pack.

[Browse packs](https://github.com/ahmedaldhraif/tawdheef/tree/main/directories) · [Add or fix a company](https://github.com/ahmedaldhraif/tawdheef/issues/new?template=directory-data.yml) · [Contribute any country](https://github.com/ahmedaldhraif/tawdheef/issues/new?template=new-country-pack.yml)

Your private tracking stays local. Connected providers communicate online. The app does not encrypt credentials at rest. Installation does not authorize applications, email, calendar writes, publishing a CV or enabling schedules.

Verify downloads against `SHA256SUMS.txt`. The source, skill, brand kit and seven pack ZIPs are separate assets. Existing users should back up their private data and keep their existing `APPLY_TRACKER_DATA` location when updating.
