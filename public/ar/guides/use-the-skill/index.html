أعدّ Tawdheef مع مساعدك

نزّل التطبيق المجاني، واربط Codex أو Claude Code وسيرتك الذاتية، ثم ابحث عن وظائف مناسبة وابنِ ملفاتك المهنية.

التثبيت

نزّل التطبيق من إصدارات GitHub وافك ضغطه كاملاً. حزمة التطبيق تتضمن Node والواجهة؛ أما نسخة المصدر فتستخدم Node.js 26 LTS أو Node 24 المحدّث، ثم:

حمّل من GitHubملاحظات الإصدار وبصمات التحقق

تصف هذه الخطوات معاينة 0.2. تحقّق من رقم الإصدار الذي تنزّله وميزاته الفعلية وحالة توقيعه؛ نسخة المعاينة ليست توزيعاً موقّعاً.

npm start

حزمة دليل الشركات بيانات، وليست تطبيقاً. لا يصرّح التثبيت بالتقديم أو تسجيل الدخول إلى الخدمات نيابةً عنك.

ربط المساعد

افتح Connections → Assistant واختر Codex أو Claude Code مرة واحدة. انسخ طلب الإعداد إلى محادثتك الحالية في ذلك التطبيق، واستخدم المجلد المحدد فيه. أعد استخدام اتصالاتك وإعداداتك العاملة، وأكمل موافقات المشروع والخدمات بالطريقة المدعومة.

طلب الإعداد
Set up Tawdheef in this local workspace using the Codex or Claude Code client I am using. Read AGENTS.md and docs/FIRST-RUN.md. Reuse working project settings and my actual client tools. Connect the local tracker MCP, then call get_agent_context and get_capabilities. All external connections, including Tabbio MCP, email, calendar, browser/computer use and my password manager, belong to this client. Guide only the missing setup and let me complete sign-in, trust and consent. Check actual access and report bounded non-secret connection metadata to Tawdheef. Do not copy provider credentials, browser profiles or password stores into the tracker. Do not change app code, submit applications, create profiles, share a CV, send messages, change calendar events or create schedules during setup.

يتولى عميلك الفعلي النموذج وTabbio MCP والبريد والتقويم والمتصفح والتحكم بالكمبيوتر ومدير كلمات المرور. يضيف توظيف الأدوات والسجلات المحلية؛ ولا يبدأ مساعداً آخر أو ينسخ بيانات الدخول. لا تقرأ محادثات الويب إعدادات stdio المحلية بمجرد وجودها.

إذا كنت تفضّل الطرفية

اختر أمراً واحداً داخل مجلد المصدر:

npm run agent -- codex

أو اختر Claude Code بدلاً منه:

npm run agent -- claude-code

تُنشأ إعدادات MCP والمهارة لهذا المشروع فقط. استخدم --check للمعاينة، وادمج الحقول الناقصة عند وجود تعارض بدلاً من استبدال إعداداتك. لا تغيّر إعدادات المنزل أو الإعدادات العامة. قد يحتاج العميل إلى محادثة جديدة لتحميل MCP. لا يلزم تثبيت CLI للمساعد أو محرك متصفح داخل توظيف للوضع الافتراضي.

السيرة الذاتية

من Connections → Tabbio CV، أنشئ سيرة حقيقية في Tabbio إن احتجت، أو أعد استخدام حسابك. انسخ طلب ربط Tabbio MCP إلى مساعدك وأكمل تسجيل الدخول هناك. يستخدم المساعد أدواته لقراءة السيرة؛ ويحتفظ توظيف بالمعرّف أو الرابط ووقت التحديث دون نصها الكامل.

يمكن أن يضيف خيار الإعداد --tabbio خادم Tabbio إلى إعدادات مشروع العميل عندما تطلب ذلك. القراءة لا تتيح تلقائياً تعديل السيرة أو نشرها أو تغيير ظهورها. ملف PDF/DOCX الأصلي، حتى 10 ميغابايت، خيار محلي للرفع المصرّح به فقط. دليل ربط السيرة.

استدعاء get_agent_context وget_capabilities يرصد استخدام أدوات المتابعة. تعرض تقارير الوصول الخارجي المؤرخة Client reported أو Unknown أو Needs you؛ ولا تؤكد مستقلاً حساباً أو نموذجاً أو متصفحاً أو جدولاً. تحقق من الوصول الحالي في العميل قبل العمل.

يمكن قراءة الحالة المحلية عبر get_setup_status؛ وحتى verify:true لا يشغّل نموذجاً أو CLI أو اتصال مزود في الوضع الافتراضي. يتولى العميل الفعلي فحص أدواته والإبلاغ عن الملاحظة.

سير العمل

صفِّ الشركات أو حدّدها، ثم راجع إجراءات Run. تبدأ الوظائف المطابقة والملفات المهنية مفعّلتين؛ ويبقى إرسال السيرة للمستقبل بالبريد متوقفاً. ابدأ الجولة وألصق طلبها في محادثتك الحالية. يظهر Waiting for assistant حتى يستلم مساعدك الشركة التالية. يستخدم أدواته ويعيد التأكيدات والخطوات التي تحتاجك إلى السجلات المحلية.

Stop يلغي صلاحية الجولة؛ أوقف العمل المتبقي في تطبيق المساعد أيضاً. لا يتحكم توظيف بمحادثة تطبيق آخر. دليل الجولة.

الاستخدام

في Codex اذكر $tawdheef، وفي Claude Code استخدم /tawdheef. وضّح المهمة والأهداف والإجراءات التي تريدها.

الاتصال جاهز؟ ثبّت المهارة فقط

إعداد المشروع يثبت المهارة. إذا احتجت تعليماتها فقط في عميل مدعوم آخر:

npx skills@latest add ahmedaldhraif/tawdheef --skill tawdheef

المهارة تعليمات؛ لا تثبّت التطبيق، ولا تربط MCP أو حساباً، ولا تمنح إذن التقديم أو الإرسال. مصدر المهارة.

طلبات جاهزة

للبحث فقط:

رشّح 10 جهات في [الدليل] لوظيفة [الدور والموقع] باستخدام أدلة المصادر وسيرتي الفعلية المتاحة في هذا العميل. وضّح الملاءمة والمعلومات الناقصة. لا تقدّم أو ترسل.

لجولة محددة:

ابدأ جولة صريحة للجهات [الأسماء] في [الدليل] للوظائف [الدور والموقع]. أسمح بالتقديم للوظائف المناسبة وإنشاء الملفات المهنية عند عدم وجود وظيفة مناسبة؛ لا أسمح برسائل السيرة للمستقبل. استخدم أدواتي المصرّح بها، وتحقق من التكرار وسجّل التأكيدات وما يحتاجني.

لمراجعة العمل:

افحص محادثات طلباتي المسجلة فقط بحسابها الأصلي في هذا العميل. لخّص التغيّرات الفعلية والخطوات التالية واحفظ تقريراً محلياً. لا تبدأ جولات أو تشارك سيرة أو ترسل رسائل أو التقرير.

الصلاحيات

تغطي الجولة الأهداف والإجراءات المحفوظة فقط. الحساب والملف ورفع السيرة نتائج منفصلة عن طلب التوظيف المؤكد. قد تحتاج إلى تسجيل الدخول أو CAPTCHA أو إقرار الهوية أو موافقة الخدمة؛ وتظل خطوات LinkedIn يدوية. افحص النتيجة المجهولة قبل تكرار أي إرسال.

تُضبط المتابعة المقروءة في Settings → Monitoring ثم يُنسخ طلبها إلى العميل لإنشاء مهمة محلية عند طلبها. الحفظ والنسخ ورقم المهمة لا تثبت التشغيل. لا تبدأ المتابعة طلبات توظيف أو حسابات أو ملفات مهنية أو رسائل أو تغييرات تقويم. تبقى نماذج الخدمات المحلية وCLI القديم تحت اختيار التوافق المتقدم الصريح فقط.

الخصوصية

تبقى سجلات المتابعة والإذن والنتائج في مجلد البيانات المحلي. تظل الاتصالات الخارجية ورموزها وجلسات المتصفح وكلمات المرور في العميل أو الخدمة التي تملكها. تعالج تلك الخدمات البيانات المصرّح بها وفق شروطها. لا تحفظ كلمات المرور أو الرموز أو نص السيرة في سجلات الشركات، ولا ترسلها في دردشة أو بلاغ GitHub. موصلات التوافق المحلية القديمة تحتفظ ببياناتها الخاصة منفصلة عند اختيارها صراحة.

محلي أولاً لا يعني بلا اتصال بالإنترنت. تبقى قاعدة المتابعة والتقارير والملف الأصلي الاختياري على جهازك؛ وقد يرسل تطبيق مساعدك الطلبات والبيانات التي تصرّح بها إلى خدمات النموذج وTabbio والبريد والتقويم والمواقع عبر الإنترنت وفق شروطها وصلاحياتها.
