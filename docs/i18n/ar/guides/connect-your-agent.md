# ربط Codex أو Claude Code

استخدم تطبيق المساعد الذي تعمل فيه بالفعل. يتولى هذا التطبيق النموذج وكل الاتصالات الخارجية؛ ويضيف توظيف أدوات السجلات المحلية وتعليمات العمل.

## ربط هذا المشروع {#connect-this-project}

1. شغّل توظيف وافتح **Connections → Assistant**.
2. اختر Codex أو Claude Code مرة واحدة، ثم **Copy setup request**.
3. ألصق الطلب في محادثتك الحالية. استخدم المجلد المحلي المحدد في الطلب، وأكمل موافقات المشروع وخادم MCP المعتادة. لا يوجد رابط خاص يفتح محادثة تلقائياً.
4. اطلب استدعاء `get_agent_context` و`get_capabilities`. رصد استخدام أدوات المتابعة لا يثبت تسجيل الدخول إلى الخدمات أو وصول النموذج أو أدوات الكمبيوتر.

### ربط المشروع يدويًا {#manual-project-connection}

لنسخة المصدر، نفّذ أحد الخيارين داخل مجلد المشروع:

```sh
npm run agent -- codex
```

أو اختر Claude Code بدلاً منه:

```sh
npm run agent -- claude-code
```

تضيف الأوامر إعدادات MCP والمهارة لهذا المشروع فقط. يعرض `--check` معاينة؛ وعند وجود تعارض راجع الدمج بدلاً من استبدال إعداداتك. لا تغيّر إعدادات المنزل أو الإعدادات العامة. قد تحتاج إلى فتح محادثة جديدة لتحميل MCP. تحتوي حزمة التطبيق على Node ومساحة عمل قابلة للكتابة خارج حزمة التطبيق المثبتة.

## إضافة أدوات المتصفح عند الحاجة {#add-browser-tools-when-needed}

استخدم **Browser & computer use** لنسخ طلب فحص الأدوات المدعومة في تطبيق مساعدك. أعد استخدام جلسة المتصفح المصرّح بها، واختبر صفحة فارغة فقط. أدوات المتصفح لا تثبت القدرة على التحكم بنظام التشغيل. إذا غابت أداة أو صلاحية، اطلب خطوة إعداد مدعومة بحالة **Needs you**.

لا يحتاج الوضع الافتراضي إلى تثبيت محرك متصفح داخل توظيف. تبقى الموصلات المحلية وأدوات المتصفح القديمة تحت اختيار **Advanced compatibility → Tawdheef local adapters** الصريح.

## تثبيت المهارة فقط {#install-just-the-skill}

إذا كانت أدوات التطبيق متصلة بالفعل وتحتاج إلى تعليمات العمل فقط:

```sh
npx skills@latest add ahmedaldhraif/tawdheef --skill tawdheef
```

المهارة لا تثبّت التطبيق ولا تربط حساباً ولا تمنح إذناً بالتقديم. في Codex اذكر `$tawdheef`؛ وفي Claude Code استخدم `/tawdheef`.

## النتيجة المتوقعة {#expected-result}

يستطيع مساعدك استدعاء أدوات المتابعة المحلية. يفحص اتصالاته الخارجية الفعلية ويسجل بيانات مرجعية غير سرية مع وقت الملاحظة. يعرض التطبيق **Client reported** أو **Unknown** أو **Needs you**؛ ولا يدّعي أنه تحقق مستقلاً من حسابات مساعدك. لا يلزم وجود CLI للمساعد كي تستخدم جولة العمل المنسوخة إلى محادثتك الحالية.
