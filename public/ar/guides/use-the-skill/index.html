أعدّ Tawdheef مع مساعدك

شغّل التطبيق وانسخ طلب الإعداد إلى مساعدك، ثم اختر الشركات والإجراءات.

مراجعة المحتوى 15 نوفمبر 2026

تطبيق Codex أو Claude Code الذي تستخدمه يدير النموذج وتسجيل الدخول والأدوات الخارجية. يحتفظ توظيف بالشركات ونطاق العمل والنتائج على جهازك.

التثبيت

هذه الخطوات للمصدر الحالي بنمط Native. تنزيل v0.1.2 السابق يستخدم مسار ربط مختلفًا.

حمّل من GitHubملاحظات الإصدار وبصمات التحقق

فك ضغط المصدر وثبّت Node.js 26 LTS، ثم نفّذ في مجلده:

npm start

يبدأ التطبيق فقط، دون تسجيل الدخول أو التقديم. الحزم الموثّقة تتضمن بيئة التشغيل؛ راجع حالة إصدارات سطح المكتب.

ربط المساعد

  1. افتح الاتصالات ← المساعد واختر Codex أو Claude Code.
  2. استخدم نسخ طلب الإعداد والصقه في تطبيق مساعدك.
  3. أعد استخدام الأدوات والاتصالات الموجودة وأكمل الثقة بالخادم والدخول والموافقات في تطبيقه.
طلب الإعداد
Set up Tawdheef in this local workspace using the Codex or Claude Code client I am using. Read AGENTS.md and docs/FIRST-RUN.md. Reuse working project settings and my actual client tools. Connect the local tracker MCP, then call get_agent_context and get_capabilities. All external connections, including Tabbio MCP, email, calendar, browser/computer use and my password manager, belong to this client. Guide only the missing setup and let me complete sign-in, trust and consent. Check actual access and report bounded non-secret connection metadata to Tawdheef. Do not copy provider credentials, browser profiles or password stores into the tracker. Do not change app code, submit applications, create profiles, share a CV, send messages, change calendar events or create schedules during setup.

إذا كنت تفضّل الطرفية

الطلب المنسوخ هو المسار الأساسي. للربط اليدوي من المصدر:

npm run agent -- codex

استخدم npm run agent -- claude-code بدلًا منه لذلك المساعد. تربط الأوامر أدوات التتبع والمهارة؛ ولا تسجّل الدخول للخدمات. حزم التطبيق تستخدم مسارات Node المرفقة في طلبها.

السيرة الذاتية

افتح الاتصالات ← Tabbio CV. أنشئ سيرة عند الحاجة أو أعد استخدام حسابك، ثم انسخ الطلب إلى مساعدك. يقرأ سيرتك الحقيقية عبر أدواته. أكمل الدخول في تطبيق المساعد، دون جلسة بيانات دخول ثانية داخل توظيف.

للبريد والتقويم والمتصفح واستخدام الحاسوب وكلمات المرور طلبات مستقلة. أضف ما تحتاجه فقط. غير معروف وتحتاج إليك حالتان صحيحتان؛ وتقرير المساعد المؤرخ ليس تحققًا مستقلًا من الوصول.

إنشاء السيرة أو ربطها.

سير العمل

راجع الشركات والوظائف، واختر أهداف Run وإجراءاته، ثم الصق الطلب المنسوخ في مساعدك. يستخدم أدواته ويسجّل النتائج في توظيف. التقديم والملفات المهنية ورسائل السيرة الاختيارية إجراءات منفصلة.

Run لا يشغّل مساعدًا جديدًا. الإيقاف يلغي الصلاحية المحلية؛ أوقف العمل المتبقي في المساعد أيضًا.

الاستخدام

npx skills@latest add ahmedaldhraif/tawdheef-auto-apply-jobs --skill tawdheef

هذا يضيف التعليمات فقط، دون تثبيت التطبيق أو ربط الحسابات أو السماح بالتقديم.

طلبات جاهزة

اقرأ AGENTS.md واستدع get_agent_context وget_capabilities. استخدم سيرتي وتفضيلاتي من اتصال مساعدي لاقتراح قائمة مناسبة. لا ترسل أو تقدّم أي شيء.

الصلاحيات

إجراءات Run التي تختارها صراحةً تحدّد الصلاحية. قد تحتاج خطوات الدخول وCAPTCHA والموافقات إليك. تبقى إجراءات LinkedIn يدوية. سجّل إيصالات حقيقية لا نجاحًا مفترضًا.

الخصوصية

تبقى سجلات التتبع محليًا والاتصالات في تطبيق مساعدك. يحتفظ توظيف بالمراجع والتقارير المؤرخة، لا بنسخ من جلسات مساعدك المخفية أو نص السيرة. لا تنشر بيانات الدخول والسجلات الخاصة على GitHub.
