Tawdheef

Instructions for using the local tracker with Codex or Claude Code.

InstallUse itApplicationsPermissions

Start with the app.

Let your agent set up Tawdheef. That installs the skill and connects the project tools. To add only the skill:

npx skills@latest add ahmedaldhraif/tawdheef --skill tawdheef

Choose your client in the installer. Guidance alone does not install or start Tawdheef, connect MCP, or sign into an account.

Use it in your client.

Codex prompt
$tawdheef
Use Tawdheef. Read AGENTS.md and call get_agent_context and get_capabilities. Review my UAE directory and connected CV, then suggest a shortlist based on my role and location preferences. Do not send or submit anything.
Claude Code prompt
/tawdheef
Use Tawdheef. Read AGENTS.md and call get_agent_context and get_capabilities. Review my UAE directory and connected CV, then suggest a shortlist based on my role and location preferences. Do not send or submit anything.

Open this folder in the local client and accept its project/server trust prompt. ChatGPT and Claude web chats do not read local stdio configuration.

How applications work.

  1. Read a directory, its source evidence and your actual CV.
  2. Choose targets and explicitly start a run. Research alone does not authorize sending.
  3. The agent checks duplicates, uses your authorized browser or email connection, and records real outcomes.
  4. Review receipts, relevant replies and anything marked Needs you.

A draft, a created profile, an uploaded CV and a submitted application are different steps. An application needs a real receipt or confirmation. After an uncertain submission, inspect before retrying.

Your accounts. Your permission.

Enter credentials and complete sign-ins in Connections, never in chat. The app’s Run button requires a connected Tabbio CV. Browser applications can work without email.

Sign-ins, CAPTCHA, identity declarations and provider approvals may need you. LinkedIn application steps stay manual. A skill cannot bypass client or provider restrictions. Calendar actions need separate consent; scheduled checks never start applications or send follow-ups.

Source and help.

The app includes the skill, its references, docs/FIRST-RUN.md for setup and docs/AGENT-GUIDE.md for tools and recovery. Setup guide · Privacy.
