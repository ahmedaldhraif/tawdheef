# اربط Codex أو Claude Code

تطبيق مساعدك يوفّر النموذج والأدوات الخارجية. يوفّر توظيف السجلات المحلية وتعليمات العمل.

## ربط المشروع {#connect-this-project}

1. شغّل توظيف وافتح **الاتصالات ← المساعد**.
2. اختر تطبيقك واستخدم **نسخ طلب الإعداد**.
3. الصقه في المساعد وأعد استخدام اتصالاته، وأكمل الثقة بالخادم هناك.
4. اطلب استدعاء `get_agent_context` و`get_capabilities` و`get_native_client_status`.

تقرير المساعد المؤرخ ليس تحققًا مستقلًا من الدخول أو وصول النموذج. غياب الوصول يبقى خطوة تحتاج إليك.

### الربط اليدوي {#manual-project-connection}

من مجلد المصدر:

```sh
npm run agent -- codex
```

أو استخدم `npm run agent -- claude-code`. يعاين `--check` التغييرات. تُحفظ الإعدادات المخصصة والعامة. الحزم تستخدم طلبها ومسارات Node المرفقة.

## أدوات المتصفح {#add-browser-tools-when-needed}

انسخ الطلب من صف الاتصال المطلوب. يفحص المساعد قدراته الفعلية للمتصفح والحاسوب والبريد والتقويم وكلمات المرور. المسار الافتراضي لا يثبّت متصفحًا أو جلسة خدمة ثانية يملكها توظيف. يعتمد الدعم على تطبيقك وحسابك وصلاحياتك.
