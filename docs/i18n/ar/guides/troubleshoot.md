# حل مشكلة في الإعداد أو التشغيل

ابدأ من **الاتصالات** وانسخ الطلب المناسب. تطبيق مساعدك يدير الوصول الخارجي.

## التطبيق لا يفتح {#the-local-app-will-not-open}

للمصدر الحالي ثبّت Node.js 26 LTS ونفّذ `npm start` من مجلده. الحزمة تتضمن بيئة التشغيل؛ فك ضغطها كاملةً واستخدم مشغّلها. [حالة الإصدارات](https://github.com/ahmedaldhraif/tawdheef-auto-apply-jobs/blob/main/docs/DESKTOP-RELEASE.md).

## المساعد لا يرى الأدوات {#the-agent-cannot-see-tracker-tools}

اختره في **الاتصالات ← المساعد** والصق **طلب الإعداد** فيه. وافق على الثقة بالخادم هناك. يعاين `npm run agent -- codex --check` أو أمر Claude المكافئ إعداد المصدر. احتفظ بالإعدادات العامة.

## السيرة غير متاحة {#the-cv-is-unavailable}

استخدم **الاتصالات ← Tabbio CV** وانسخ الطلب. يفحص المساعد أدواته المصرّح بها. أكمل الدخول في تطبيقه. التقرير القديم أو المجهول لا يثبت وصولًا حاليًا.

## النماذج أو البريد غير متاحين {#browser-forms-or-email-are-unavailable}

استخدم طلب الاتصال المناسب. يحتاج مساعدك قدرات المتصفح والحاسوب والبريد وكلمات المرور الفعلية. لا تنسخ بيانات الدخول المخفية إلى التتبع أو تنشئ جلسة خدمة ثانية. الحسابات المهنية الموجودة تحتفظ بدخولها الأصلي.

## Run ينتظر المساعد {#run-says-waiting-for-assistant}

الصق الطلب في المساعد المحدد ليستلم العمل المحفوظ. Run لا يفتح مساعدًا جديدًا. قد تحتاج قيود الخدمة إلى تدخلك.

## لا يوجد فحص مراقبة حديث {#monitoring-has-no-recent-check}

افحص المهمة في تطبيق سطح المكتب وتوفر الحاسوب والمساعد وتوظيف. حفظ الطلب لا يثبت الإنشاء أو التنفيذ.

## الاستيراد غير مكتمل {#a-pack-import-looks-incomplete}

عاين الحزمة كاملةً من **خيارات القائمة ← إدارة حزم الأدلة**. تحقق من البيان وتاريخ المصدر. للحزم القديمة أجزاء CSV محتملة؛ [اتبع دليل الحزم](https://github.com/ahmedaldhraif/tawdheef-auto-apply-jobs/blob/main/docs/i18n/ar/guides/use-directory-packs.md).

## النتيجة المتوقعة {#expected-result}

خطوة واضحة أو وصول حالي ملحوظ، دون نجاح مفترض. لا تنشر السجلات الخاصة في البلاغات.
