Set up Tawdheef

Download the app and let Codex or Claude Code handle local setup while you complete your sign-ins.

On this page
What you needStart with one requestExpected result

Tawdheef is a free Auto Job Apply & Application Tracker that runs on your computer. Your Codex or Claude Code does the agent work; you use the same directory and application records.

What you need

  • A computer with Node.js 24 or newer.
  • One installed, signed-in Codex or Claude Code.
  • Your real CV information. You can create or connect your Tabbio CV during setup.

The app is free. Your assistant account and connected services may have their own plans or usage costs.

Start with one request

  1. Open Get started and download the app’s source ZIP, then extract it. A country directory ZIP is an add-on, not the app.
  2. Open the extracted Tawdheef folder in your chosen assistant.
  3. Paste the setup request. Your agent handles the local commands and guides you through the sign-ins that need you.
Setup request
Set up Tawdheef for me in this folder. Read AGENTS.md and docs/FIRST-RUN.md. Check what already works, then install missing project dependencies, start the app, add browser tools, and connect this project to the assistant I am using. Keep existing settings and data. Help me create or connect my free Tabbio CV using only my real information. Guide me through only the sign-ins or choices that need me; I will enter credentials in the local connection form. Check setup again and tell me the next step. Use get_setup_status (verify:true for the final check), or the equivalent CLI command. Do not change the app's code or design, send applications, create calendar events, or enable schedules during setup.

When the local app opens, complete your sign-ins in Connections. Choose your assistant there and use Check connections. First launch needs internet to install the project dependencies. Get started also has the manual commands.

Expected result

The tracker opens on your computer. Your agent reports Ready or gives you one concrete next step, such as signing in or connecting your CV. Setup does not start applications.
