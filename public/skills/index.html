Install the skill.

The recommended app setup installs it for your chosen client. To install guidance separately:

npx skills@latest add ahmedaldhraif/tawdheef --skill tawdheef

Choose Codex or Claude Code in the installer. A skill does not install the app, connect tools, sign into accounts or give permission to apply. What it can do.

Ask for what you need.

In Codex, start with $tawdheef. In Claude Code, use /tawdheef.

Find a shortlist
Use Tawdheef. Read AGENTS.md and call get_agent_context and get_capabilities. Review my UAE directory and connected CV, then suggest a shortlist based on my role and location preferences. Do not send or submit anything.
Apply to selected targets
Use Tawdheef. Read my selected companies and connected CV. Start an application run for these named targets, check for duplicates, and help me apply. Record each real outcome with its evidence. Hand off anything that needs my sign-in or approval.
Review progress
Use Tawdheef. Review my tracked applications and refresh replies for the relevant threads. Summarise real changes and next actions. Do not start new applications or send follow-ups.

Use the installed local client. ChatGPT and Claude web chats do not read local stdio settings. Connect your local agent.
