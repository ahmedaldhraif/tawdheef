# قدّم للوظائف وأنشئ ملفاتك المهنية

أنت تختار الشركات والإجراءات. ينفّذ مساعدك العمل الخارجي ويسجّل توظيف النطاق والأدلة.

## قبل البدء {#before-you-start}

اربط المساعد والسيرة عبر [الاتصالات](https://github.com/ahmedaldhraif/tawdheef-auto-apply-jobs/blob/main/docs/i18n/ar/guides/use-the-skill.md#agent). اطلب البحث في صفحات التوظيف بسيرتك وتفضيلاتك وراجع قائمة الوظائف. تعذّر الصفحة لا يثبت غياب الفرص.

## الشركات والإجراءات {#choose-companies-and-actions}

رشّح أو حدّد الشركات وافتح **Run** وراجع الأهداف:

- التقديم للوظائف التي تدعمها خبرتك وأهليتك.
- استكمال الحسابات والملفات ورفع السيرة وقوائم المواهب حيث تتاح، بصورة مستقلة عن التقديم.
- رسائل السيرة فقط: خيار مستقل غير مفعّل افتراضيًا لعناوين توظيف منشورة ومتحقق منها.

## ابدأ التشغيل {#start-the-run}

يحفظ Run النطاق وينسخ طلبه. الصقه في مساعدك المحدد. ينتظر توظيف استلامه للعمل؛ ولا يشغّل نموذجًا أو عملية CLI جديدة.

يستخدم المساعد أدوات المتصفح والبريد وكلمات المرور لديه. تتولى فتح القفل والدخول وCAPTCHA والموافقات. تبقى إجراءات LinkedIn يدوية.

## النتائج الحقيقية {#track-real-outcomes}

الحساب أو الملف أو رفع السيرة ليس تقديمًا. سجّل كل نتيجة منفصلة. الطلبات ورسائل السيرة تحتاج إيصالات حقيقية. افحص النتيجة المجهولة قبل تكرار المحاولة.

## الإيقاف والمحاولة {#stop-or-retry}

الإيقاف يلغي الصلاحية المحلية؛ أوقف العمل المتبقي في مساعدك أيضًا. الإجراءات الجديدة تحتاج Run صريحًا جديدًا، بعد فحص الإيصالات المجهولة.

## متابعة الوظائف {#monitor-new-jobs}

استخدم [المراقبة للقراءة فقط](https://github.com/ahmedaldhraif/tawdheef-auto-apply-jobs/blob/main/docs/i18n/ar/guides/replies-and-reports.md#monitor-new-jobs). المراقبة لا تسمح بالتقديم أو إنشاء الملفات.
