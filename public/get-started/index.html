1. Get Tawdheef.

Download and extract the app. Open that folder in your installed, signed-in Codex or Claude Code. You only need one.

Download Tawdheef source

Get the source on GitHub.

2. Ask your agent to set it up.

Paste this into your client:

Setup request
Set up Tawdheef for me in this folder. Read AGENTS.md and docs/FIRST-RUN.md. Check what already works, then install missing project dependencies, start the app, add browser tools, and connect this project to the assistant I am using. Keep existing settings and data. Guide me through only the sign-ins or choices that need me; I will enter credentials in the local connection form. Check setup again and tell me the next step. Use get_setup_status (verify:true for the final check), or the equivalent CLI command. Do not change the app's code or design, send applications, create calendar events, or enable schedules during setup.

Node.js 24 or newer is required. Your agent can check what is missing and guide installation; complete any system permission prompt yourself. It preserves existing settings and data, starts the local app and checks readiness.

Accept the project/server trust prompt when shown. You may need a new chat to load the tools. ChatGPT and Claude web chats do not read local stdio settings; use the local client above.

Prefer manual setup?

In a terminal in the extracted folder:

npm start

This installs missing locked dependencies, builds the screen and starts your local tracker. Windows users can also open Start Tawdheef.cmd.

To add browser tools and connect an existing client chat:

npm run setup -- --browser
npm run agent -- codex --browser
npm run agent -- claude-code --browser

Run only the command for your chosen client. These create project settings and install the skill; they do not sign you in. Preserve custom settings if a conflict is reported. Full merge instructions are in docs/FIRST-RUN.md in the download. About the skill.

3. Complete your connections.

In the local app, open Connections. Choose your assistant under AI assistants, connect your Tabbio CV, then choose Check connections. Enter credentials only in the local connection form, never in chat.

A connected Tabbio CV is required for Run. You can browse directories and track applications without it. No CV yet? Create a free Tabbio CV. Tabbio’s connection guide.

Email is optional for browser applications. Connect your own mailbox for email applications and reply checks; Gmail and Outlook need your own OAuth registration or a supported bridge. Your agent can guide the provider steps. Calendar and schedules can wait.

4. Choose where to apply.

When connections are ready, open Run, describe the jobs you want and choose companies. Starting Run authorizes real applications to those targets. Sign-ins, CAPTCHA and provider approvals may still need you.

Prefer to research first? Ask your agent:

Find a shortlist
Use Tawdheef. Read AGENTS.md and call get_agent_context and get_capabilities. Review my UAE directory and connected CV, then suggest a shortlist based on my role and location preferences. Do not send or submit anything.

Costs, privacy and local requirements.

Tawdheef is free and MIT licensed. Your AI client, model usage and connected providers may have their own plans or costs. Tawdheef does not require its own model API key.

The app and your agent run on your computer. The default server is available only there; the website does not host your private tracker or make it available on your phone.

Tracking records and connection credentials are stored locally. Local credentials are not encrypted at rest. AI clients, Tabbio, email providers and careers sites communicate online under their own permissions. Read the privacy guide.

This website has no visitor analytics scripts or tracking pixels. Hosting may create access logs. Tabbio links include readable referral parameters; its own plans and privacy terms apply.

Something needs attention?

Use Connections → Check connections, or ask your agent to check setup again. npm run doctor reports installed tools. The download includes docs/FIRST-RUN.md and docs/AGENT-GUIDE.md for troubleshooting.
