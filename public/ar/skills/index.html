ابدأ من هنا

شغّل التطبيق، واختر مساعدك في الاتصالات، ثم انسخ إليه طلب الإعداد.

تستخدم هذه التعليمات المصدر الحالي بنمط Native. تنزيل v0.1.2 السابق له خطوات مختلفة. استكشف بيانات الشركات أولًا.

نزّل المصدر الحاليعرض المشروع أو نسخه من GitHub
  1. 1

    شغّل توظيف

    نزّل المصدر وفك ضغطه، ثم شغّل npm start من مجلده. استخدم Node.js 26 LTS للمصدر.

    npm start
  2. 2

    اختر مساعدك

    افتح الاتصالات ← المساعد، واختر Codex أو Claude Code، ثم انسخ طلب الإعداد والصقه في تطبيق مساعدك.

    npm run agent -- codex

    لربط Claude Code يدويًا بدل Codex: npm run agent -- claude-code

    هذه أوامر ربط محلية اختيارية. أعد استخدام الاتصالات الموجودة في مساعدك؛ لا تضف جلسات بريد أو متصفح ثانية داخل توظيف.

  3. 3

    اربط سيرتك عبر مساعدك

    افتح الاتصالات ← Tabbio CV. انسخ طلب الربط إلى مساعدك وأكمل تسجيل الدخول والموافقة في تطبيقه.

    أنشئ سيرتك مجانًااربط سيرتك الذاتية

    السيرة والبريد والتقويم والمتصفح وكلمات المرور تبقى في تطبيق مساعدك. تعرض الاتصالات حالة غير معروفة، تحتاج إليك، أو تقريرًا مؤرخًا من المساعد.

    Run ينسخ طلبًا محددًا لمساعدك. راجع الإجراءات والشركات قبل لصقه.

جهّز التطبيق، واعثر على وظائف تناسبك، وأنشئ ملفاتك المهنية لفرص مستقبلية.
