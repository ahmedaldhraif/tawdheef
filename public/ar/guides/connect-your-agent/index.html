تطبيق مساعدك يوفّر النموذج والأدوات الخارجية. يوفّر توظيف السجلات المحلية وتعليمات العمل.

ربط المشروع

  1. شغّل توظيف وافتح الاتصالات ← المساعد.
  2. اختر تطبيقك واستخدم نسخ طلب الإعداد.
  3. الصقه في المساعد وأعد استخدام اتصالاته، وأكمل الثقة بالخادم هناك.
  4. اطلب استدعاء get_agent_context وget_capabilities وget_native_client_status.

تقرير المساعد المؤرخ ليس تحققًا مستقلًا من الدخول أو وصول النموذج. غياب الوصول يبقى خطوة تحتاج إليك.

الربط اليدوي

من مجلد المصدر:

npm run agent -- codex

أو استخدم npm run agent -- claude-code. يعاين --check التغييرات. تُحفظ الإعدادات المخصصة والعامة. الحزم تستخدم طلبها ومسارات Node المرفقة.

أدوات المتصفح

انسخ الطلب من صف الاتصال المطلوب. يفحص المساعد قدراته الفعلية للمتصفح والحاسوب والبريد والتقويم وكلمات المرور. لا يثبّت توظيف متصفحًا أو جلسة خدمة ثانية يملكها التطبيق. يعتمد الدعم على تطبيقك وحسابك وصلاحياتك.

المهارة فقط

npx skills@latest add ahmedaldhraif/tawdheef-auto-apply-jobs --skill tawdheef

المهارة تعليمات، وليست أدوات أو تسجيل دخول. الإعداد الأول.

النتيجة المتوقعة

يستخدم مساعدك أدوات التتبع ويسجّل قدراته الملحوظة. ملف الإعداد وحده لا يعني اتصال الحساب.
