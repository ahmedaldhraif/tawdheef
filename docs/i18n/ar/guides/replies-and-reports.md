# تابع الردود والتقارير

تقرأ محادثتك الحالية في Codex أو Claude Code المصادر الخارجية بأدواتها المصرّح بها. يحتفظ توظيف بالمتابعة والنتائج المحلية، ولا يفتح صندوق بريد أو تقويماً آخر في الوضع الافتراضي.

## راجع التقدّم الآن {#check-progress-now}

1. افتح سجل الشركة والإرسال الأصلي. راجع الرسائل المتعلقة بالطلبات المتابَعة فقط، وفي الحساب والمحادثة الأصليين.
2. اطلب من مساعدك فحص التغيّرات الفعلية وتسجيل دليلها وخطوتها التالية. خطأ أداة ليس رفضاً، وغياب الرد ليس دليلاً على نتيجة الطلب.
3. أنشئ تقريراً محلياً عند الطلب. حفظ التقرير لا يصرّح بإرساله، ولا تبدأ تذكيرات المتابعة رسالة تلقائياً.

```text
افحص الردود المتعلقة بمحادثات طلباتي المسجلة فقط، باستخدام حسابي الأصلي في هذا التطبيق. لخّص التغيّرات المثبتة وما يحتاج تدخلي، واحفظ تقريراً محلياً. لا تبدأ طلبات أو ملفات مهنية، ولا تشارك سيرتي أو ترسل رسائل أو التقرير.
```

تظل رسائل أو أحداث الحساب غير المتعلقة بالسجلات خارج النطاق. إذا تغيّر الحساب الأصلي أو غاب إثباته، سجّل **Needs you** بدلاً من نسب المحادثة إلى حساب آخر.

## أضف جدولًا زمنيًا عند الحاجة {#add-a-schedule-when-you-want-one}

1. افتح **Settings → Monitoring** واختر المصادر والنطاق المطلوبين. البريد يقتصر على المحادثات المتابَعة؛ والتقويم يحتاج إلى معرّفات فعلية اختارها الشخص وأبلغ عنها المساعد.
2. اختر تكرار الطلب ووقته، ثم انسخ طلب إعداد الجدول إلى تطبيق مساعدك. حفظ التفضيلات أو نسخ الطلب لا ينشئ مهمة ولا يثبت أنها تعمل.
3. ينشئ العميل مهمة محلية مدعومة فقط عند طلبها. يحتاج العمل إلى الكمبيوتر وتطبيق المساعد وتوظيف متاحة؛ ولا يشكّل `/loop` المؤقت دليلاً على مهمة Desktop دائمة.

تعيد `check_updates` طلب قراءة محدداً `readRequest`؛ وينفّذ العميل القراءة عبر أدواته الفعلية ثم يسجل `sourceRead` وأدلة المصدر. يحدّ التقويم القراءة بالتقويم المختار والأيام الأربعة عشر القادمة. تحتاج النتيجة الفارغة أو غير المتغيرة إلى فحص المصدر نفسه؛ والقراءة الناقصة تبقى مجهولة أو جزئية. لا تبدأ المتابعة طلبات أو حسابات أو ملفات مهنية، ولا ترفع أو تشارك سيرة، ولا ترسل أو تغيّر تقويماً.

تبقى فحوص التطبيق القديمة وإعدادات إرسال التقارير متاحة فقط في وضع **Tawdheef local adapters** المختار صراحة. التقارير المحلية متاحة في الوضع الافتراضي.

## النتيجة المتوقعة {#expected-result}

تعرض المتابعة آخر فحص ونتيجته والتحديثات المستندة إلى أدلة وما يحتاجك. حالة **Client reported** أو رقم مهمة محفوظ ليس تحققاً مستقلاً من الجدول. تبقى البيانات غير المقروءة ومشاهدات السيرة غير المؤكدة مجهولة، ولا تتحول إلى صفر.
