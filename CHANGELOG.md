## 0.1.0 — public preview candidate

- One local screen with customizable directory tabs, contacts, tracking status and next actions.
- Original 772-record UAE research snapshot with evidence and missing-data notes.
- Shared SQLite records through the screen, CLI and 43 stdio MCP tools.
- Multi-select Run filters for company types and locations drawn from each directory.
- Optional progress column and reports for accounts, profiles, CV uploads and CV-only sends, distinct from job applications.
- Local account adapters for Gmail, Outlook, Google/Outlook/iCloud Calendar and optional Tabbio CV.
- Explicit application runs, receipt-based outcomes, duplicate protection and read-only recovery for uncertain sends.
- Local background reply checks and reports, with separate calendar consent.
- First-launch dependency installation, project-only Codex/Claude setup and an optional reusable skill.
- Source/skill/directory release archives, checksums, private-file checks and fresh-download verification.

This entry describes the prepared candidate. It does not claim GitHub publication or authenticated live-provider verification.
