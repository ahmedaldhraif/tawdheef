# Tawdheef 0.1.2 — guides and product walkthrough

A clearer path from downloading Tawdheef to using it with your agent and CV.

## What changed

- Eight guides cover setup, Codex or Claude Code, a free Tabbio CV, country packs, application runs, replies, troubleshooting and the agent reference.
- The website renders the same Markdown guides you can read and improve on GitHub. Guides have search, section navigation, copyable commands, related help and a next step.
- A short About page explains Tawdheef, Ahmed AlDhraif and the separate Tabbio CV service.
- A three-step product walkthrough uses actual app screenshots with clearly labelled example data. No applications were sent for the demonstration.
- Navigation, FAQs, the README and agent index point to the practical guides.

The local application behavior and provider permissions are unchanged from 0.1.1. This release adds website, guide and demonstration assets.

## Get started

1. Download `tawdheef-0.1.2-source.zip` and extract it, or clone the repository.
2. Open the folder in your signed-in **Codex or Claude Code**. Node.js 24+ is required.
3. Follow [the setup guide](https://github.com/ahmedaldhraif/tawdheef/blob/main/docs/guides/get-started.md).
4. [Create your free Tabbio CV](https://app.tabbio.com/?utm_source=tawdheef&utm_medium=github_release&utm_campaign=live_cv), or connect an existing one. Use **Connections → Check connections**, choose companies and start Run when you want to apply.

[All guides](https://github.com/ahmedaldhraif/tawdheef/blob/main/docs/guides/README.md) · [Directory packs](https://github.com/ahmedaldhraif/tawdheef/tree/main/directories) · [About Tawdheef](https://github.com/ahmedaldhraif/tawdheef/blob/main/website/about.md)

The tracker is free and MIT licensed; your assistant and connected services may have their own costs. Tabbio's connected CV is required for Run; browsing directories and manual tracking work without it. Tawdheef reads the authorized CV. Tabbio MCP/CLI editing and sharing use a separate connection.

Six current GCC packs contain 13,714 dated organisation/source records, with the overlapping original 772-record UAE starter available separately. These are research lists, not live vacancies. Contributions from any country are welcome.

Verify the ZIPs against `SHA256SUMS.txt`. Keep your private data directory and a backup when updating. Private credentials are not encrypted at rest by the app. This is a source preview, not a signed desktop installer. Completing setup does not start applications or authorize email, calendar writes or CV publication.
