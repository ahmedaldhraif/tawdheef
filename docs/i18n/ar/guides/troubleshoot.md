# عالج مشكلة في الإعداد أو التشغيل

ابدأ بفحص الاتصالات والخطوة التالية التي يعرضها التطبيق. حافظ على الإعدادات وبيانات المتابعة الموجودة أثناء معالجة الجزء الناقص.

## حدّد ما يمنعك من المتابعة {#find-the-blocker}

1. إذا لم يفتح التطبيق، شغّل الأوامر أدناه من مجلد Tawdheef.
2. إذا فتح التطبيق، انتقل إلى **Connections** واختر مساعدك ثم **Check connections**.
3. اتبع الحل المناسب أدناه، ثم أعد الفحص.

```sh
npm start
npm run doctor
```

## التطبيق لا يبدأ {#the-app-will-not-start}

ثبّت [Node.js 24 أو أحدث](https://nodejs.org/en/download)، ثم أعد فتح الطرفية وشغّل `npm start`. يحتاج التشغيل الأول إلى الإنترنت لتثبيت الاعتماديات. على Windows، إذا منع PowerShell تشغيل `npm.ps1`، فاستخدم `npm.cmd start` أو **Start Tawdheef.cmd**. لا تحتاج إلى تغيير سياسة التنفيذ في النظام.

إذا كان تطبيق آخر يستخدم المنفذ، احتفظ بنص الخطأ واطلب من مساعد الإعداد تحديده. لا تشغّل نسخة ثانية من المتتبّع بمجلد بيانات مختلف.

## المساعد مثبّت لكن Run لا يستطيع استخدامه {#the-assistant-is-installed-but-run-cannot-use-it}

افتح Codex أو Claude Code وأكمل تسجيل الدخول. اختر المساعد نفسه في Connections وأعد الفحص. أخطاء حدود الاستخدام تخص حساب المساعد؛ عالجها قبل جولة جديدة. إذا لم تظهر الأدوات في محادثة موجودة، فاقبل طلب الثقة بالمشروع أو الخادم وابدأ محادثة جديدة.

## السيرة متصلة لكن لا يمكن قراءتها {#the-cv-is-connected-but-cannot-be-read}

افتح **Connections → Tabbio CV** وأكمل تسجيل الدخول أو منح الوصول. إذا احتاج التطبيق إلى تعيين أداة قراءة السيرة، فاطلب من مساعد الإعداد فحص الأداة المتاحة فعلًا. لا تخمّن معرّف السيرة أو أسماء الأدوات. أعد **Check connections** بعد ذلك.

## المتصفح أو البريد غير متاح {#browser-forms-or-email-are-unavailable}

للنماذج على المواقع، اطلب من مساعد الإعداد تثبيت المتصفح عبر `npm run setup -- --browser`. مع Gmail أو Outlook، أكمل إعداد OAuth لمرة واحدة من الرابط الموجود في Connections. يستخدم iCloud Mail كلمة مرور خاصة بالتطبيق من Apple تُدخلها في النموذج المحلي.

قد يتطلب CAPTCHA أو تسجيل الدخول تدخّلك حتى بعد نجاح الإعداد. إذا لم تتأكد من نتيجة الإرسال، فابحث عن إيصال قبل تكرار المحاولة.

## يبدو استيراد الحزمة غير مكتمل {#a-pack-import-looks-incomplete}

فك ضغط ZIP أولًا واقرأ `manifest.json` → `files.imports`. استورد كل أجزاء CSV المذكورة إلى التبويب نفسه. راجع التنبيهات بدل استبدال الدليل الموجود أو حذف سجلات للوصول إلى عدد معيّن.

## النتيجة المتوقعة {#expected-result}

يعرض فحص الاتصالات **Ready**، أو يحدّد خطوة متبقية يمكنك إكمالها. تبقى سجلات المتابعة وإعداداتك المخصّصة محفوظة.
