# Start your first application run

Run lets your chosen Codex or Claude Code work through the companies you choose, using your real CV and keeping a record of what happens.

## Before you start

Have a readable connected CV, a signed-in assistant and a directory with records. Browser tools support website forms. A connected mailbox is needed for email applications and reply checks; it is optional for browser forms.

## Choose the work

1. Open **Connections → Check connections** and resolve any required next step.
2. Choose your directory and companies in the app, then open **Run**. Describe the roles and work locations you actually want.
3. Review the company scope and your instructions. Narrow the company type or location if needed, and check the number of companies to attempt.
4. Press **Run** to authorise applications for those targets within this run.
5. Use **View progress** to see the current company, outcomes and next actions. Use **Stop** when you want to end further work; completed results remain recorded.

Your agent checks current roles against your CV and preferences. If no suitable role is found, it records that result and the next step. A failed search is not evidence that no role fits.

## When a site needs you

Sign-ins, CAPTCHAs and identity declarations may require you to finish a step. LinkedIn application steps remain manual. A blocked company gets an actionable next step so the queue can continue with others.

Later runs skip confirmed applications and can retry unfinished work. An uncertain send or form submission must be checked for a receipt before retrying.

## Expected result

You see actual outcomes for the attempted companies: an application with its confirmation, no suitable role found, or a clear **Needs you** item. Any account creation or CV upload along the way is recorded separately; it does not prove an application was submitted.
