A pack adds a company list.

It adds organisations, careers links and source notes to your local tracker. It does not install code or apply to jobs.

1

Download and extract

Choose a country above and extract its ZIP from GitHub.

2

Add it to Tawdheef

Create or select a directory, then choose List options → Import list. Select a CSV from the pack and review the preview.

3

Use it with your agent

Import every numbered CSV part into the same directory. Your agent can now read the list, match it to your CV and help you apply.
