npx skills@latest add ahmedaldhraif/tawdheef-auto-apply-jobs --skill tawdheef

Get started

Start the app, choose your assistant in Connections, then copy its setup request.

These steps match the current Native source. The older v0.1.2 download uses a different setup. Explore company data first.

Get current sourceView or clone on GitHub
  1. 1

    Start Tawdheef

    Download and extract the source, then run npm start in its folder. Use Node.js 26 LTS for source.

    npm start
  2. 2

    Choose your assistant

    Open Connections → Assistant and choose Codex or Claude Code. Copy the setup request into that client.

    npm run agent -- codex

    For manual Claude Code setup instead of Codex: npm run agent -- claude-code

    These are optional local connection commands. Reuse your client’s existing connections; do not create a second mailbox or browser session in Tawdheef.

  3. 3

    Connect your CV through your agent

    Open Connections → Tabbio CV. Copy its request into your agent and complete provider sign-in and consent in that client.

    Create your free CVConnect your CV

    CV, email, calendar, browser and password-manager access stay in your actual client. Connections shows Unknown, Needs you or a dated Client reported status.

    Run copies a scoped request for your agent. Review its actions and companies before pasting.
