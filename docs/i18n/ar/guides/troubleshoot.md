# عالج مشكلة في الإعداد أو التشغيل

حدّد هل المشكلة في التطبيق المحلي، أو ربط أدواته، أو اتصال خارجي يملكه تطبيق مساعدك. حافظ على بياناتك وإعداداتك العاملة؛ ولا تتجاوز موافقات العميل أو الخدمة.

## حدّد ما يمنعك من المتابعة {#find-the-blocker}

افتح **Connections** واختر المساعد الصحيح. **Unknown** تعني غياب تقرير حديث، و**Needs you** تعني خطوة تحتاجك، و**Client reported** ملاحظة مؤرخة من المساعد وليست تحققاً مستقلاً. انسخ طلب إعداد الخدمة المطلوبة إلى محادثتك الحالية؛ لا تدخل كلمات مرور أو رموز وصول في الدردشة أو سجل شركة.

استدعاء أدوات المتابعة يثبت استخدامها محلياً، ولا يثبت تسجيل الدخول إلى البريد أو قدرة النموذج أو التحكم بالكمبيوتر. افحص الخدمة نفسها عبر أدوات العميل التي تدعمها.

## التطبيق لا يبدأ {#the-app-will-not-start}

فك ضغط حزمة التطبيق كاملة واستخدم مشغّلها. لنسخة المصدر، استخدم Node.js 26 LTS أو Node 24 المحدّث، ثم `npm start`. شغّل `npm run doctor` لبيانات التثبيت والتطبيق، واحتفظ برسالة الخطأ. لا تحذف مجلد البيانات ولا تبدأ نسخة أخرى بمسار خاص مختلف لتجاوز المشكلة.

إذا منع Windows تشغيل `npm.ps1`، استخدم `npm.cmd start` أو ملف `.cmd` المرفق؛ لا تحتاج إلى تغيير سياسة النظام العامة. تعارض المنفذ قد يعني أن التطبيق يعمل بالفعل.

افحص التثبيت وحالة التطبيق دون تغيير الحسابات:

```sh
npm run doctor
npm run background:status
```

## المساعد مثبّت لكن Run لا يستطيع استخدامه {#the-assistant-is-installed-but-run-cannot-use-it}

في الوضع الافتراضي، لا يشغّل Run برنامج CLI للمساعد. يحفظ الجولة وينسخ طلبها؛ ألصقه في محادثتك الحالية. **Waiting for assistant** تعني أن العميل لم يستلم الهدف التالي بعد. افحص ربط MCP المحلي والمجلد ومسار البيانات، وأكمل موافقة المشروع أو افتح محادثة جديدة عند الحاجة. لا يوجد رابط خاص أو واجهة خفية تتيح لتوظيف بدء محادثة مكانك.

تخص فحوص CLI وتسجيل دخوله وضع **Advanced compatibility → Tawdheef local adapters** فقط. لا تبدّل إليه تلقائياً لتجاوز قيد في عميلك.

## السيرة متصلة لكن لا يمكن قراءتها {#the-cv-is-connected-but-cannot-be-read}

افحص اتصال Tabbio MCP الفعلي في تطبيق مساعدك وأكمل تسجيل الدخول أو الموافقة هناك. تأكد أنه قرأ المصدر الحقيقي؛ وجود رابط أو تقرير قديم لا يكفي. يحتفظ توظيف ببيانات مرجعية فقط، ولا يوفر قارئ `get_cv` في الوضع الافتراضي. لا تنشئ سيرة بديلة أو تغيّر ظهورها لتجاوز خطأ.

## المتصفح أو البريد غير متاح {#browser-forms-or-email-are-unavailable}

تحقق من الأدوات المدعومة والصلاحيات في التطبيق المختار. اختبار المتصفح لا يثبت التحكم بنظام التشغيل؛ ومدير كلمات المرور قد يحتاج إلى فتحه أو موافقتك. استخدم الحساب والجلسة الموجودين، ولا تنسخ ملفات المتصفح أو رموزه إلى توظيف. إذا غابت الأداة فسجّل خطوة **Needs you** واضحة.

بعد نتيجة إرسال أو نموذج غير مؤكدة، افحص الإيصال الأصلي قبل المحاولة. لا تنشئ مفتاحاً جديداً لتجاوز حجز غير محسوم. زر **Stop** يلغي صلاحية الجولة المحلية؛ أوقف العمل المتبقي في تطبيق المساعد أيضاً.

## يبدو استيراد الحزمة غير مكتمل {#a-pack-import-looks-incomplete}

راجع بيان الحزمة وعدد ملفات CSV، واستورد كل الأجزاء المرقمة في الدليل المحلي نفسه. الفهرس المختصر ليس ملف الاستيراد الكامل. حافظ على المعرّفات والأدلة الأصلية ولا تستبدل متابعة الشخص ببيانات البحث.

## النتيجة المتوقعة {#expected-result}

حالة معروفة بدليلها أو خطوة محددة تحتاجك. لا تعلن نجاح تسجيل الدخول أو الإرسال أو الجدول من إعداد محفوظ أو صفحة مفتوحة أو اختبار واجهة محلي.
