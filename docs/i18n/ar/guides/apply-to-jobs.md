# ابدأ أول جولة تقديم

يتيح **Run** لمساعدك في Codex أو Claude Code العمل على الشركات التي تختارها، باستخدام سيرتك الحقيقية وتسجيل ما يحدث.

## قبل البدء {#before-you-start}

تحتاج إلى سيرة ذاتية متصلة يمكن قراءتها، ومساعد مسجّل الدخول، ودليل يحتوي على سجلات. تُستخدم أدوات المتصفح للنماذج على المواقع. ربط البريد مطلوب للتقديم بالبريد وفحص الردود، وهو اختياري لنماذج المتصفح.

## حدّد العمل المطلوب {#choose-the-work}

1. افتح **Connections → Check connections** وأكمل أي خطوة مطلوبة.
2. اختر الدليل والشركات، ثم افتح **Run**. حدّد الوظائف ومواقع العمل التي تريدها فعلًا.
3. راجع الشركات المشمولة وتعليماتك. ضيّق نوع الشركات أو الموقع عند الحاجة، وتحقق من عدد الشركات التي ستُحاول التقديم إليها.
4. اضغط **Run** للسماح بالتقديم إلى هذه الجهات ضمن الجولة الحالية.
5. استخدم **View progress** لمتابعة الشركة الحالية والنتائج والخطوات التالية. اضغط **Stop** لإيقاف العمل اللاحق؛ تبقى النتائج المكتملة محفوظة.

يفحص مساعدك الوظائف الحالية وفق سيرتك وتفضيلاتك. إن لم يجد وظيفة مناسبة، يسجّل النتيجة والخطوة التالية. تعذّر البحث لا يثبت عدم وجود وظيفة مناسبة.

## عندما يحتاج الموقع إلى تدخّلك {#when-a-site-needs-you}

قد تحتاج إلى إكمال تسجيل الدخول أو CAPTCHA أو إقرار متعلق بالهوية. تبقى خطوات التقديم على LinkedIn يدوية. إذا تعذّر إكمال العمل لدى شركة، تُسجّل خطوة واضحة لتتمكن الجولة من متابعة الشركات الأخرى.

تتجاوز الجولات اللاحقة الطلبات المؤكدة، ويمكنها إعادة محاولة العمل غير المكتمل. إذا كانت نتيجة إرسال بريد أو نموذج غير مؤكدة، يجب البحث عن إيصال قبل المحاولة مجددًا.

## النتيجة المتوقعة {#expected-result}

ترى نتائج فعلية للشركات التي جرت محاولة التقديم إليها: طلبًا مع تأكيده، أو عدم العثور على وظيفة مناسبة، أو بندًا واضحًا بحالة **Needs you**. يُسجّل إنشاء الحساب أو رفع السيرة بصورة منفصلة؛ أي منهما لا يثبت إرسال طلب توظيف.
