Tawdheef / توظيف | Brand system v1.0
Selected direction: 04 Arabic Grid. Date: 13 November 2026.

Names
- English logo artwork: tawdheef.com, lowercase and kept together.
- Prose and page titles: Tawdheef.
- Arabic: توظيف, with natural shaping and no letter spacing.
- Intended domain: www.tawdheef.com.
- Powered by Tabbio is an optional, separate endorsement.

Start here
Open index.html from the running local app at /brand/ for the interactive guide.
SVG masters are outlined paths: no font installation is required to display them.
Use mark.svg for the symbol; logo-latin, logo-arabic, logo-bilingual or logo-stacked
for lockups. Purple versions pair the purple mark with ink lettering; ink and
white variants are supplied. Use mark-16, mark-24 and mark-32 at those small sizes.

Browser and app icons
favicon.svg responds to a dark browser tab but never animates. favicon.ico has
the exact 16,24,32,48 and64pixel PNG frames. App icons use an opaque purple canvas
with safe margins, including for a maskable icon. apple-touch-icon.png is180pixels.
github-social.png is1280x640. Transparent symbol and logo PNGs are included.

Motion
Everyday marks are static. The busy SVG alternates the two dot pulses only for
real loading. It preserves the body and respects prefers-reduced-motion.
The guide includes an explicit entrance demonstration, with no keyboard-triggered
decorative movement. A busy mark needs a visible/accessible text status nearby.
Use the supplied React component and CSS from the source kit for integration.

Fonts and source
Manrope and Noto Kufi Arabic are bundled with their full SIL OFL1.1 licences.
The working tracker keeps its installed platform font. Tabbio's original mark
is retained separately and is not part of the core Tawdheef mark.
tokens.json contains geometry, colours, minimum sizes, spacing and motion values.
asset-inventory.json lists file hashes. The source/ directory contains build
recipes and React integration code; run build recipes from their original
scripts/branding locations in the full source checkout.

The intended domain and GitHub release are not published by creating this kit.
