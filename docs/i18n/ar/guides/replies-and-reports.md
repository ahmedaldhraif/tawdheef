# تابع الردود والفرص الجديدة

يقرأ مساعدك المصادر الخارجية. يحفظ توظيف نطاق المراقبة والأدلة المسجّلة.

## راجع التقدّم {#check-progress-now}

اطلب فحص المحادثات المرتبطة بالطلبات المتتبعة فقط، من البريد الأصلي. سجّل التغييرات والخطوة التالية. فشل القراءة ليس رفضًا.

> راجع ردود طلباتي المتتبعة ولخّص الأدلة والخطوات التالية. احفظ تقريرًا محليًا. لا ترسل متابعات أو تبدأ طلبات توظيف.

التقرير المحلي ليس رسالة بريد. الإرسال يحتاج طلبًا صريحًا مستقلًا وأدوات بريد مساعدك.

## أضف جدولًا عند الحاجة {#add-a-schedule-when-you-want-one}

افتح **المراقبة (Monitoring)** واختر المصادر والتكرار والمنطقة الزمنية والشركات، ثم **نسخ طلب الجدولة**. الصقه في تطبيق سطح المكتب المدعوم. ذلك التطبيق يدير المهمة المحلية؛ الحفظ أو نسخ الطلب لا ينشئها.

معرّف المهمة المبلّغ عنه ليس دليل تنفيذ. نتيجة الفحص المؤرخة دليل منفصل. يجب توفر الحاسوب والمساعد وتوظيف. الوصول الناقص يبقى خطوة تحتاج إليك.

## تابع الوظائف الجديدة {#monitor-new-jobs}

اختر المصادر والشركات. يقرأ المساعد صفحات التوظيف أو المصادر المدعومة ويقارن الفرص بسيرتك وتفضيلاتك. يمكن مراقبة الملفات الموجودة ومحادثات الطلبات والتقاويم المحددة صراحةً للقراءة فقط.

المراقبة لا تقدّم أو تنشئ وتعدّل ملفات أو ترفع وتشارك السيرة أو ترسل رسائل أو تستخدم كلمات المرور أو تغيّر التقويم. راجع الفرصة وابدأ Run مستقلًا للتصرف. نمط Native لا يشغّل قواعد التقديم الدوري القديمة التي يديرها التطبيق.
